# 💻 Desafio Frontend - Fullstack Developer

Neste desafio, você deverá desenvolver a interface de uma aplicação web com **página de login**, **dashboard (home)** e um **CRUD de usuários**. O projeto deverá ser desenvolvido utilizando **TypeScript** e um dos frameworks listados abaixo:

## ⚙️ Tecnologias Permitidas

- [ ] ReactJS
- [ ] VueJS
- [ ] Angular

> É obrigatório o uso de **TypeScript**.

---

## 🎯 O que deve ser implementado

### 1. Página de Login
- Campos: e-mail e senha
- Validação básica de formulário
- Redirecionamento para a home após login

### 2. Página Home (Dashboard)
- Boas-vindas ao usuário logado
- Link ou botão para acessar o CRUD de usuários

### 3. CRUD de Usuários
- Listagem de usuários com paginação ou scroll infinito
- Cadastro, edição e remoção de usuários
- Formulário com validação

> A persistência dos dados pode ser simulada via requisições a uma **API real**.

---

## ✅ Requisitos Obrigatórios

- Utilização de **TypeScript**
- Utilização de **componentização e boas práticas**
- Separação de responsabilidades (serviços, componentes, páginas)

---

## ⚡ Diferenciais

- Design responsivo
- Integração com a API fornecida no repositório backend
